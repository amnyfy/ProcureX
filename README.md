# ProcureX — AI-Powered Tender Intelligence & Procurement Platform

ProcureX is an enterprise-grade AI-powered Tender Intelligence and Procurement Platform built for businesses to discover government tender opportunities, analyze complex tender specification PDFs, evaluate eligibility and winning probability, and track high-value opportunities through a streamlined procurement pipeline.

---

## Features

- **JWT Authentication & User Management**: Secure user registration, password hashing, and token-based authentication.
- **Company Management**: Pipeline organization attached to enterprise profile metrics.
- **Tender Management**: Complete CRUD operations, category filtering, keyword search, and deadline tracking.
- **Government Tender Aggregation**: Adapter-based public tender aggregation engine.
- **Central Public Procurement Portal (CPPP) Integration**: Connector for eprocure.gov.in notices.
- **PDF Text Extraction**: Automatic PDF document parsing using `pypdf`.
- **AI Tender Analysis**: NLP requirement extraction, eligibility scoring (0-100%), and AI-estimated winning probability.
- **Bid Management**: Pipeline tracking (analyzed, submitted, awarded, rejected) synced with PostgreSQL.
- **Responsive Web Dashboard**: Built with React, Vite, Tailwind CSS, and Lucide Icons.
- **Interactive OpenAPI/Swagger API**: Built-in API documentation via FastAPI.

---

## Architecture

- **Frontend**: React, Vite, React Router, Axios, Tailwind CSS
- **Backend**: Python, FastAPI, SQLAlchemy, Uvicorn
- **Database**: PostgreSQL
- **AI Engine**: Heuristic NLP Requirement Matcher & Decision Support Analyzer (`app/ai/analyzer.py`)
- **Government Data**: `GovernmentTenderSource` Adapter Engine (`app/services/government_tenders/`)

## Local Setup & Development

### 1. Prerequisites
- Python 3.10+
- Node.js 18+
- PostgreSQL server (Port 5432 or 5433)

### 2. Backend Setup
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt  # or install fastapi uvicorn sqlalchemy psycopg2-binary pypdf python-jose passlib python-multipart requests python-dotenv

# Configure environment variables
cp .env.example .env

# Initialize database schema
python create_tables.py

# Run FastAPI backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. Frontend Setup
```bash
cd procurex-frontend
npm install

# Configure environment variables
cp .env.example .env

# Start React/Vite development server
npm run dev
```

## Government Tender Data & Compliance

### Source & Ingestion
ProcureX uses an extensible `GovernmentTenderSource` adapter pattern (`CPPPSource`) to ingest public tender notices spanning key organizations such as **NHAI, ISRO, AIIMS, NTPC, and CRIS**.

### CAPTCHA & Anti-Bot Compliance Notice
Official government portals (e.g. CPPP / eprocure.gov.in) enforce dynamic CAPTCHA validation and rate limiting on interactive search forms. In strict compliance with security and terms of service guidelines, ProcureX **does not bypass CAPTCHAs, rate limits, or access controls**.

### Data Source Status
In the current development environment, the `CPPPSource` adapter verifies live portal connectivity and normalizes public CPPP tender opportunities into a **seed/demo dataset** (`CPPP (Demo/Seed Data)`). The underlying adapter architecture is production-ready for direct integration when official bulk e-procurement API tokens or RSS feeds are provisioned.

## AI Analysis Disclaimer

> **AI Winning Probability Disclaimer**: The winning probability score generated by ProcureX is an AI-generated decision-support estimate based on heuristic requirement extraction from available tender specification text. It should not be considered a guarantee of tender award or contract outcome.
